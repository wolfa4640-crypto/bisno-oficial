BISNO MARKETPLACE SOCIAL v3.0 — SISTEMA DE LOJAS

Inclui o marketplace inicial, contas, anúncios, perfis, mensagens/notificações já existentes e sistema de lojas:
- qualquer utilizador autenticado pode ativar uma loja na própria conta;
- painel privado da loja com visitas, seguidores, contactos e quantidade de anúncios;
- contagem separada de visualizações da loja, seguidores e contactos iniciados por conversa;
- cada visitante é contado no máximo uma vez por dia por loja (por sessão);
- seguir/contatar a própria loja é bloqueado;
- estatísticas armazenadas em SQLite.

EXECUÇÃO LOCAL
1. Instala Node.js LTS.
2. Na pasta que contém server.js, executa: npm install
3. Define SESSION_SECRET com pelo menos 32 caracteres aleatórios.
4. Executa: npm start
5. Abre http://localhost:3000

RENDER
Build Command: npm install
Start Command: npm start
Environment: NODE_ENV=production, SESSION_SECRET=<chave aleatória com pelo menos 32 caracteres>.

PERSISTÊNCIA REAL NO RENDER
A instância gratuita padrão pode perder os ficheiros locais ao reiniciar ou fazer deploy. Para preservar base de dados, sessões e fotografias, adiciona um Persistent Disk (plano que suporte disco) com mount path /var/data e configura:
DATA_DIR=/var/data
UPLOADS_DIR=/var/data/uploads
A aplicação cria a pasta de uploads automaticamente. A base de dados SQLite e a base de sessões ficarão dentro do disco persistente. Não guardar SESSION_SECRET no repositório.

TESTES
Executa npm test para verificar sintaxe. Isto não substitui um teste end-to-end no Render.

MÉTRICAS
- Visitas: abertura de perfil público da loja, deduplicada por sessão e dia.
- Seguidores: contas únicas que seguem a loja.
- Contactos: clientes únicos por canal; o contacto interno é registado quando começa uma conversa sobre um anúncio. O endpoint de contacto WhatsApp está disponível para ligar ao botão WhatsApp na interface.
- Anúncios: número de produtos do proprietário.

PAGAMENTOS
O Bisno não processa pagamentos. Comprador e vendedor combinam pagamento e entrega diretamente.
